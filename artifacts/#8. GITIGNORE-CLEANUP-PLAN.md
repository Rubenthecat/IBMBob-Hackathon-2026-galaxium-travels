# Plan: Full .gitignore Cleanup + Committed Artefact Removal

## Top-Level Overview

A thorough audit found **multiple categories** of committed files that should never be
in a repository: a Python virtual environment with machine-specific absolute paths, build
output directories, runtime log files, compiled artefacts, and a `dist/` Vite build.
Every item in this plan is confirmed **on disk and tracked by git**; nothing is speculative.

The fix is:
1. `git rm --cached` every tracked item that belongs in `.gitignore`.
2. Patch the root `.gitignore` so these cannot re-appear.
3. Commit both changes together.

No source code, `setup.ps1`, or service logic requires changes.

## Sub-Tasks

### Sub-Task 1: Remove Python venv and cache artefacts from git index

**Intent**
Un-track the Python virtual environment and all `__pycache__` / `.pytest_cache`
directories in `booking_system_backend/`. The `.venv` directory is the primary cause
of the backend startup failure (its `pyvenv.cfg` encodes `C:\Users\ruben\...`).

**Expected Outcomes**
- `booking_system_backend/.venv/`, `__pycache__/`, `services/__pycache__/`,
  `tests/__pycache__/`, and `.pytest_cache/` are removed from the git index.
- `setup.ps1` will recreate `.venv` fresh on the next run because its
  `if (-not (Test-Path ".venv"))` guard (line 213) will now trigger.

**Todo List**
1. `git rm -r --cached booking_system_backend/.venv/`
2. `git rm -r --cached "booking_system_backend/__pycache__/"`
3. `git rm -r --cached "booking_system_backend/services/__pycache__/"`
4. `git rm -r --cached "booking_system_backend/tests/__pycache__/"`
5. `git rm -r --cached booking_system_backend/.pytest_cache/`
6. Verify with `git status`.

**Relevant Context**
- `booking_system_backend/.venv/pyvenv.cfg` lines 1, 4, 5: the hardcoded absolute paths.
- `setup.ps1` lines 213–233: venv creation and backend launch — no changes needed.
- Root `.gitignore` already has `__pycache__/` (line 2) and `.pytest_cache/` (line 53)
  but is missing `.venv/` for this service — fixed in Sub-Task 5.
